## How to read this

- **Not a precision rate.** Batches were chosen differently in each region, came from different detectors, and many
  have not been answered. A rate computed from this table would mix all of that.
- **"Already recorded" is a useful outcome, not a miss.** It means the detector found a real monument that the public
  register did not show. It is not a discovery.
- **No reply is not a no.** Heritage officers answer when their workload allows. Unanswered locations are not
  counted as negative.
- **Authorities differ.** Some English HERs record any unrecorded earthwork as "undated"; some German authorities
  only answer whether something is a burial mound. The tiers in [VERIFICATION.md](VERIFICATION.md) apply the same
  test to all of them.
